## Anti-slop

For UI, copy, accessibility, responsive layout, or code comment work, read `.agents/skills/antislop/SKILL.md` first, followed by the relevant skill:

- UI and visual design: `.agents/skills/antislop-ui/SKILL.md`
- Copy and interface text: `.agents/skills/antislop-copywriting/SKILL.md`
- Accessibility and interaction: `.agents/skills/antislop-human/SKILL.md`
- Responsive layout: `.agents/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.agents/skills/antislop-code/SKILL.md`

References to `antislop.md` in the packaged skills mean `.agents/skills/antislop/SKILL.md` in this project. The skills are already installed; skip the first-run installation wizard.

Before UI work, establish whether anti-slop applies during implementation or as an audit after implementation. Reuse a choice already supplied by the user. Read `DESIGN.md` if present, or use the user's explicit design brief; installing these skills alone does not establish a new visual direction or authorize a redesign.

Run the applicable delivery checks when implementing or auditing UI. Installation details and the pinned upstream revision are in `.agents/ANTISLOP.md`.
