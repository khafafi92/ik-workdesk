# Pengaturan Modul

Sistem administrator dapat membuka **Pengaturan Sistem > Pengaturan Modul** untuk mengaktifkan atau menonaktifkan kelompok modul di sidebar.

Setiap sakelar berlaku untuk semua pengguna, termasuk sistem administrator. Modul nonaktif disembunyikan dari navigasi dan URL halamannya ditolak. Modul aktif tetap mengikuti hak akses role dan izin pengguna yang sudah ada. Sistem administrator tetap dapat membuka halaman pengaturan untuk mengaktifkan kembali modul.

Pengaturan berlaku pada kelompok menu utama, termasuk semua halaman dan submenu di dalam kelompok tersebut. Menu yang belum pernah diatur tetap aktif secara default.
